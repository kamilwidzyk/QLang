Error code format: <exception>-<code>    (eq. ATE-3)
<exception> is short of exception name(if possible, this needs to be unique)
<code> - starts from 1 and goes up with every place the exception can be raised at(file path + line number)

This list will later be used to make documentation of the error codes

List format:
<exception> -> <exception short>
    <code>: <file_path> 
        <Explain when the exception is raised and why>
