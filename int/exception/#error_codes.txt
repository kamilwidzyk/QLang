Error code format: <exception>-<code>    (eq. ATE-3)
<exception> is short of exception name(if possible, this needs to be unique)
<code> - starts from 1 and goes up with every place the exception can be raised at(file path + line number)

This list will later be used to make documentation of the error codes

List format:
<exception> -> <exception short>
    <code>: <file_path> 
        <Explain when the exception is raised and why>
        TEST: <path to the test that throws this error>

    <code>: REMOVED (this means this error code was used for something and it got removed, we do not reuse codes)

# code: ATE-3   
Those comments are written above the raised exception,
Use 'Find in files' to find the place of the code

Some of the below error are not displayed correcly(or not displayed at all)
Main place catcher needs to be updated
