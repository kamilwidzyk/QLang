\section{Error codes}\label{sec:error_codes}

When the interpreter encounters any error, it appears in the interpreter terminal formatted inside a red box. 
Errors are not displayed inside place consoles. After the error is printed out, execution of places is interrupted and interpreter exits.

\begin{figure}[h]
    \centering
    \includegraphics[width=0.8\textwidth]{chapter-E-error-codes/img/error_box.png}
    \caption{Description of error box elements}
    \label{fig:error_box_description}
\end{figure}

\noindent Description of each element inside the error box:
\begin{itemize}
    \item \textbf{Type} - When the error happend, can be
        \begin{itemize}
            \item SYNTAX ERROR - Syntax error was detected in the initial check, code execution did not start. 
            \item RUNTIME ERROR - Error was discovered during code execution.
        \end{itemize}   
    \item \textbf{Title} - Category of the error
    \item \textbf{Code} - Code directly related to specific error. For the full list refer to list below. There are NO codes for syntax errors(code is not displayed).
    \item \textbf{Description} - Short description of what went wrong
    \item \textbf{Context} - Shows few lines above and below. Yellow mark indicates the most likely cause. In rare cases there might be no context to show.
\end{itemize}

\noindent Every error code follows the same format:
\begin{center}
\texttt{<letters>-<number>}
\end{center}

\noindent The letters are compiled of capital letters of the exception that were raised - like a category of what happend. 
The number narrows it down to the precise case. Below is a table of every set of letter and the section it is described at. 
Letters are unique to each exception. Some error numbers in the sequence might be missing(eg. 1, 2, 4, 5).
