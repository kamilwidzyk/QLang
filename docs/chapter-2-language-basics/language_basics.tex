\section{Language Basics}\label{sec:language-basics}

This chapter covers the fundamental building blocks of QLang: how programs are
structured, the available data types, variables, operators, and control flow
constructs.

% ─────────────────────────────────────────────
\subsection{Program Structure}\label{sec:program-structure}

A QLang source file (extension \texttt{.ql}) consists of a sequence of
top-level items. Each item is one of the following:

\begin{itemize}
    \item A \texttt{place} declaration.
    \item A function declaration (at global place).
    \item A statement (at global place).
\end{itemize}

Items are executed in the order they appear. The global place is the implicit
default place and is always present. When a named place is declared, its body
executes when the program starts.

\subsection{Data Types}\label{sec:data-types}

QLang has four built-in variable types, designed to cover both classical and
quantum computation:

\begin{center}
\begin{tabular}{|p{2cm}|p{10cm}|}
\hline
\textbf{Type} & \textbf{Description} \\
\hline
\texttt{state} &
    A quantum state (qubit or qubit register). Represents a quantum system that
    can be in superposition and can be entangled with other qubits. Collapsed
    to a classical value via the \texttt{measure} keyword. \\
\hline
\texttt{obs} &
    An observation, a classical integer. Stores the result of a measured state or
    any integer value. Supports arithmetic, comparison, and bitwise operations.
    Bit-width is specified as \texttt{obs x[N]}. \\
\hline
\texttt{num} &
    A universal numeric type. It dynamically handles both integers 
    and floating-point numbers, automatically adapting its internal 
    representation based on the assigned value and performed operations. Used 
    for all classical numerical computations. \\
\hline
\texttt{text} &
    A string of characters. Used for textual data, print formatting, and string
    operations. \\
\hline
\end{tabular}
\end{center}

\subsubsection{Constants}

The \texttt{const} keyword can be applied to any variable declaration to
prevent reassignment after initialisation.

Variables can be declared as mutable first and then locked with the
\texttt{const} keyword. Once a variable has been marked as constant, it cannot
be reassigned anymore. Attempting to modify a constant at runtime produces an
error.

variable, updates it, and then freezes it so later assignments are rejected.

\input{chapter-2-language-basics/qlang/control_flow.tex}

\subsubsection{For Loop}

The \texttt{for} loop iterates over a numeric range with an optional step.
The syntax is \texttt{for <var> from <start> to <end> step <step>}. For a
descending loop, \texttt{step = -1}; for an ascending loop, \texttt{step = 1}.
When \texttt{step} is omitted, it defaults to \texttt{-1} for descending loops
and \texttt{1} for ascending loops.

\subsubsection{While Loop}

The \texttt{while} loop repeats its body as long as the condition holds.

\subsubsection{Break and Continue}

\texttt{break} exits the nearest enclosing loop immediately.
\texttt{continue} skips the rest of the current iteration and proceeds to the
next one.

\subsection{Input and Output}\label{sec:io}

\subsubsection{Output}

QLang provides three output statements:

\begin{itemize}
    \item \texttt{print(...)} — prints values without a trailing newline.
    \item \texttt{println(...)} — prints values followed by a newline.
    \item \texttt{debug(x)} — prints debug information.
\end{itemize}
